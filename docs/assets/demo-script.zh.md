# 60 秒视频脚本：带收据的派活

[English](demo-script.md) · 中文

给你自己用真的 Claude Code 和 Codex 录。README 里 15 秒的循环动画（[demo.svg](demo.svg)，`python scripts/make_demo.py`
生成）讲的是同一件事，但用的是替身 CLI；这一份是真跑。

**录之前**
- 一个一次性的小仓库，带测试（不放真实工作、真实名字）：比如 `~/demo/shop`，`pytest -q` 是绿的。终端 1280×720 以上，
  字号 18 以上，提示符简单（`$`），路径里不出现你的名字（改 `PS1` / 提示符，`cd` 到短目录）。
- `ccx doctor` 全绿；先打开一次 `ccx ui`，别让浏览器在镜头里弹询问。
- 关掉别的标签页和通知。先空跑一遍：真跑大约一分钟，等待那段剪掉。

| 时间 | 画面 | 旁白（或字幕） |
|---|---|---|
| 0–5 秒 | 在仓库里打开 Claude Code | "Claude Code 要把一件杂活交给 Codex。" |
| 5–15 秒 | 在 Claude Code 里说：*"加一个 `slugify()` 和测试；通过 ccx 交给 Codex，用 `pytest -q` 验收。"* Claude 先跑 `ccx route`，再跑 `ccx run --to codex --check "pytest -q" …` | "ccx 挑一个最便宜、又大概率做得完的 Codex 模型。" |
| 15–30 秒 | 运行中（等待剪掉），然后最后一行：`status=done ok=true check=passed review=pass cost=~$…` | "Codex 一次做完。ccx 自己又跑了一遍验收，另一家的模型审了改动。" |
| 30–45 秒 | `ccx ui` → 这件任务 → 点完成的那块：谁做的、花费、验收（带输出）、审查、改了哪些文件 | "每次派活都有收据：花了多少、验收跑没跑、谁审的。撤回也只是一个按钮。" |
| 45–55 秒 | `ccx ui` →"实测与 token 去向"：历史 hc1 表，旁边加 hc2 字幕 | "历史 hc1，旧代码，2026-10-29：做对 29/30，每次成功比自己做便宜约 30%，用时约 3 倍。候选 hc2 成本和墙钟都更高：$0.088 对 $0.063，168 对 61 秒。self 未重跑，原因没有隔离。" |
| 55–60 秒 | `pipx install git+https://github.com/SUPERD6/relayline` 和 `ccx demo` | "不用账号先看看：`ccx demo`。" |

**说实话**（和 README 同一套规矩）
- hc1 标明历史实验、旧代码、2026-10-29（`docs/measured.zh.md`）；便宜约 30% 不描述当前版本。
  带限制：说"没有看到更差"，不说"更准"；说"用时约 3 倍"，绝不说"更快"。
  同时展示 hc2：每成功成本（干净行）$0.088 对 $0.063，墙钟中位 168 对 61 秒，均更高。
  self 和内置子智能体本轮未重跑，代码和沙箱环境的影响没有分开。如果 UI 只显示 hc1，就加 hc2 字幕，不能把旧表当候选结果。
- 画面上的花费是这次运行的 API 等价价格；如果录的是订阅账号，要说"API 等价"。
- 真跑时如果升级了模型、验收失败或审查提了问题，照实保留或者重录——不改数字。
- 画面里不出现个人信息：真实项目名、路径、邮箱、账号名都不要（看一眼终端标题栏和浏览器地址栏）。
