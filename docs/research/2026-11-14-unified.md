## Why G3/G4 did badly

Read-only investigation: when the cheap rung was wrong, the lead's `--check` was the whole existing test suite,
which already passed before the change (or failed the same way before and after), so it could not see the new
requirement, yet ccx treated it as acceptance. The escalation logic itself had no bug. Improvements: #325
(sensitivity check, off by default, #333) and #326 (write a failing test before delegating). Handover overhead
(brief, CLI start, check, review) also dominates on these tasks that self finishes in about 40 s, hence 2.7–5× wall
time. Counting only Claude's own spend, ccxlong used 24% of self ($0.25 vs $1.03) at the same number right; the
pre-registration judged total spend and had no bar for this.
