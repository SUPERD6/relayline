## 指标
抓错率 = 错的被拦 / 15。误拦率 = 对的被拦 / 14。Unknown 单列，分子分母都写。花费 API 等价美元。

## 判定（按顺序）
1. 实际完成回放的单元 < 25：**Unknown**，报告原因，不补跑超预算。
2. 用最坏口径（Unknown 在错的里算没抓到，在对的里算误拦）：抓错 ≥ 8/15 且误拦 ≤ 2/14 → **Pass**。
3. 用最好口径（Unknown 在错的里算抓到，在对的里算没拦）：抓错 < 8/15 或误拦 > 2/14 → **Fail**。
4. 其余：**Unknown**（差别全部来自 Unknown，先查 Unknown 原因，不把它当 Pass）。
