## Metrics
Defined in section 2 of the engineering standards. Correct = all hidden tests pass. Cost per success = total spend over all attempts (including failures) / number correct, API-equivalent dollars. Report both all rows and env_clean rows. Median and cumulative wall-clock are report-only. Also report the number of units judged small and done by self, the actual tier, and the source of user_words.

## Verdict (in order)
1. env_clean < 50/60, or env_clean < 25 in either group: **Unknown**; do not re-run beyond budget.
2. Threshold A: candidate correct >= self correct - 1. Threshold B: candidate cost per success <= 1.2 x self cost per success. If either group has 0 correct, write the total spend and judge threshold B Unknown.
3. A and B both pass on all rows = **Pass**; either fails on all rows = **Fail**. If all rows and env_clean rows disagree, judge **Unknown** and say so.
4. One round is only a signal. Only Pass goes on to a phase 5 re-run and only then can a default change be decided; Fail keeps it off by default and the negative result is published. If a change is made after failure, go back to the development set and reserve new final tasks.
