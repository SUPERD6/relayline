## Question A: with ccx installed but not called on small jobs, does it get worse (phase 3 round 2)
- Comparison: `self` vs `ccx2inst`. Both groups use the same prompt, neither mentions ccx; the `ccx2inst` lead additionally carries ccx's managed prompt block and hooks.
- Tasks: 30 small tasks re-chosen with a new salt, not using the phase 0 or 3 tasks. Selection without looking at model results. One round.
- Limit: under `flags` isolation the real ccx home cannot be used (it needs user credentials), so the prompt block and hooks are injected through launch arguments. If the injected content cannot be made the same as a real install, write Unknown and do not run.
- Thresholds (carried over from plan phase 3, not relaxed): correct >= self - 1; cost per success <= 1.2 x self. env_clean < 24 rows in either group: Unknown. All rows and clean rows disagree: Unknown.
- A pass only means "the overhead of being installed but not called is acceptable"; it does not mean delegation pays off.

## Question B: in a long session, delegating to Codex, can it markedly cut Claude quota use
- The flow is exactly the same as phase 4: `self` vs `ccxlong`, 4 tasks per game, 2 games.
- Tasks: 8 new tasks, selection rules as in `scripts/eval/long_selection.json`, not using the development and final tasks, and only repositories already in the local cache. If fewer than 8, say so; do not lower the rules.
- Metric: Claude-side cost = lead + the money spent on Anthropic models in sub-agents and review. Codex-side cost is reported separately.
- Thresholds (all rows):
  1. Claude-side total cost <= 0.5 x self;
  2. ccxlong correct >= self correct;
  3. 16 rows env_clean >= 12, each group >= 6, every game finished; otherwise Unknown.
- All pass = Pass, and it can only be said as "in the tested scenario, saves Claude quota". **Total cost and wall-clock have no threshold but must be reported in the same row**: phase 4 had total cost 2.05x and median wall-clock 5.5x, and that price must be in the same sentence. It cannot be described as cheaper or faster.
- The phase 4 Claude-side numbers (not pre-registered) count only as an observation that generated the hypothesis. Even a Pass is one round of new data; public numbers need two rounds per the plan, so one more round is needed before going public.
