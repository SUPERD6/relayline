## 本次改动

1. 用户原话的已有优先级不变。新增 `ccx/review_contract.py`，从改动前 snapshot
   提取 Python 接口；回放明确使用已提交的原始 stub，不读隐藏测试。保留签名、
   类型、默认值、继承、装饰器和 docstring，剥离函数实现。缺失或截断标 Unknown。
2. 生成前先列 `behaviors.json`：原文、接口假设、返回类型/形状/单位、测试计划与
   未覆盖项，再读实现。清单与接口另存证据；不新增通过或拦截条件。
3. 引用规范化去掉 inline/reference Markdown link 的目标/标签，保留显示文字；
   slash 分隔词不再误拼。改写、改数字、无意义引句仍拒绝。
4. `review.tests_model` 接受原有 model 字符串及 `vendor:model[:effort]`；
   `--review-model` 是保留 `--reviewer-model` 的别名。默认配置仍空，不启用新行为。
5. 跨厂商、原文依据、实际测试执行、失败再确认和原生预算限制不变；
   错误自写测试继续 Unknown，不直接当作实现错误。

接口摘要只能传已有规定。没有返回类型/单位的原始 stub 仍不足以补全接口，缺失历史
原话也不能重建。本次属于工程修复，不声称通过科学或效果验收。
